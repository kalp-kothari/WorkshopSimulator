# WorkshopSimulator

A full-stack workshop registration platform built with **Next.js, Prisma, PostgreSQL, Stripe, and Auth.js**.

Users can browse workshops, sign in with Google/GitHub, register through Stripe Checkout, and receive confirmation emails. Admins can manage workshops and registrations through a dedicated dashboard.

### Tech Stack

* **Frontend:** Next.js, React, Tailwind CSS
* **Backend:** Next.js API Routes, Prisma
* **Database:** PostgreSQL (Neon)
* **Authentication:** Auth.js + Google/GitHub OAuth
* **Payments:** Stripe Checkout + Webhooks
* **Email:** Resend
* **Deployment:** Vercel

### Features

* 🔐 Google & GitHub authentication
* 📚 Workshop browsing and detailed pages
* 💳 Secure paid registration with Stripe
* 📩 Automated registration emails
* 👤 User dashboard
* 🛠️ Admin dashboard
* 🌙 Light/Dark mode
* 📱 Responsive UI
* 🗄️ PostgreSQL database with Prisma migrations
